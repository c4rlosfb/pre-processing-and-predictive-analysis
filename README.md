# pre-processing-and-predictive-analysis
Análise preditiva e pré-processamento sobre a base de dados: Breast Cancer Wisconsin; Além de não utilizar nenhuma biblioteca de alto nível pronta, apenas NumPy e Math; O escopo do projeto envolveu a estruturação das seguintes técnicas: Limpeza e Ajuste, Balanceamento e Amostragem e Redução de Dimensionalidade.
